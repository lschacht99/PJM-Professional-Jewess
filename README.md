Public website for a developing educational and professional-experience initiative. This repository originally hosted Professional Jewess.

- GitHub Pages publishes `/` from the main branch.
- Legacy HTML routes redirect to relevant new pages.
- Participant and partner forms submit to existing insert-only Supabase `pj_applications`/`pj_inquiries` tables; never expose service-role credentials.
- Current photographs are illustrative concepts, not documentation of actual events or partnerships.
- Programs marked proposed are not confirmed.
- Legal and tax-exempt status are not implied or asserted.
- Historical version preserved on `archive-professional-jewess-2026-10-14`. Existing database records have not been removed.
- Site owners should add a dedicated contact mailbox, review RLS/spam protection, legal/privacy language, and educational documents before promoting widely.
